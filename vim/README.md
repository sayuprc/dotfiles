# vim

普段は Neovim (`nvim/`) を使う

ここは、たまに素の Vim を開いたときのための、プラグインを使わない最小限の設定

## Required

- vim

## セットアップ

このディレクトリで実行する

```bash
mise run all
```

`~/.vimrc` にこのディレクトリの `.vimrc` へのシンボリックリンクを張る

## キー操作

| キー | 動作 |
| --- | --- |
| `jj` (挿入モード) | ノーマルモードに戻る |
| `-` | 上下に分割する |
| `\|` | 左右に分割する |
| `Ctrl-h` / `Ctrl-j` / `Ctrl-k` / `Ctrl-l` | 左 / 下 / 上 / 右のウィンドウへ移動する |
